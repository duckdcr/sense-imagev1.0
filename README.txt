批量场景生图工具

使用方法：
1. 双击 启动.bat。也可以双击 start.bat。
2. 等浏览器自动打开。
3. 在右侧共享任务区输入 API Key；所有功能共用。然后按当前功能页上传图片或选择素材。
4. 数据库批量需要先切换到“数据库批量”，选择任务方式，再点“读取数据库”。仅切换板块不会读取数据库。
5. 数据库批量必须先选择保存目录。可选择自动保存 JPG、WebP，或两种格式同时保存。
6. “继续未完成”会读取数据库中的待处理 SKU，并跳过所选目录进度清单里已经完成的 SKU。
7. 每张成功后立即写入所选目录，再更新同目录下的 sence-image-progress.json；中途失败或关闭页面，下次选择同一目录即可继续。
8. “重新生成全部”会读取全部合格 SKU，并覆盖所选目录中的同名结果文件。生成或保存失败时，原文件不会提前删除。
9. 工具只读取数据库素材和 SKU 信息，不写 sku_product_image.scene_image_url；URL 由外部流程处理。
10. 最大并发数可输入 1-500，默认 20。遇到上游限流时工具会自动降低一次并重试；网络不稳定时也可手动调低。
11. 手动上传生成成功的图片会自动保存到“生成历史”，可在页面右上角打开。
12. 页面仍保留“下载选中”和“导出WebP”，可将已生成结果另存到其他目录。
13. 成功任务会自动移入“已完成”列表；等待、生成中和失败任务留在“任务列表”。完成任务不会被后续开始命令重复生成。
14. 用完后回到启动窗口，按回车关闭本地服务。
15. 面料源图使用 {sku}_detail；圆孔白底图输出为 {sku}_grommet.webp，韩褶白底图输出为 {sku}_double-pinch.webp；场景图生成输出为 {sku}_sence.jpg。文件名不支持自定义前后缀。
16. “多提示词生图”可对同一张参考图填写多条独立提示词；提交后可以继续追加任务或更换参考图，旧任务不会清空。
17. 多提示词生图中的完成结果会移入“已完成”，任务行会显示等待生成、生成中、已暂停、生成失败或已完成。
18. “格式转换”可批量把 JPG 转为 WebP；长边超过 4000px 时缩小到 4000px，其他图片保持原尺寸，质量为 90。
19. 白底图和场景图的“修改提示词”会读取工具文件夹 config\prompts.json 中当前生效的版本；点击“保存”成功后，新提交的生图任务立即使用修改后的提示词。
20. 提示词不再保存在浏览器缓存中。关闭浏览器或重启工具不会丢失，复制整个工具文件夹时也会一并带走。
21. 如果提示词输入错误，可点击当前功能页的“恢复默认提示词”；确认后只恢复当前功能对应的源码默认提示词，不影响另一类提示词。
22. 不建议手动修改或删除 config\prompts.json；请优先使用页面中的“修改提示词”和“恢复默认提示词”。

Windows 便携交付：
- 支持 Windows 10/11 64 位。
- 接收方无需安装 Node.js 或 npm，必须保留 runtime、node_modules、assets、public、src、scripts 和 config 目录。
- 将整个 sense-imagev1.0 文件夹复制到目标电脑，双击“启动.bat”即可使用。
- API Key 不写入工具配置文件，接收方仍需在页面右侧自行输入。

数据库配置：
- 默认读取 C:\报价\.env，数据库名 curtain_pricing。
- 可用 CURTAIN_DB_ENV_FILE 指定其他 .env。
- 可用 SKU_IMAGE_LOCAL_ROOT 和 SKU_IMAGE_BASE_URL 覆盖数据库素材的本地读取根目录和 URL 前缀。
- 工具不会在网页中显示数据库密码。

注意：
- 不要删除 runtime 文件夹，里面是自带的 Node.js。
- 历史记录保存在工具文件夹下的 data/history；压缩给同事时如果不想带历史，可以删除 data 文件夹。
- 如果 3456 端口被占用，启动器会自动尝试后面的端口。
- 生成失败时可先把并发数调低再试。
- “重新生成全部”会覆盖所选目录里的同名输出文件，请确认任务方式和目录后再开始。
